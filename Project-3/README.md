# Project 3 - WebGL Shaders

## Files

A collection of WebGL applications that procedurally generate shapes using vertex and fragment shaders.

[Triangle](3_sided_triangle.html) - A wireframe equilateral triangle drawn using a line loop and a procedural vertex shader.

[Polygon](10_sided_polygon.html) - A filled 10-sided convex polygon drawn using a triangle fan with a uniform variable controlling the number of vertices.

[Star](5_pointed_star.html) - A five-pointed star drawn using a triangle fan, with alternating vertex radii to create the points.

[Rotating Star](rotating_star.html) - The same five-pointed star but with a time uniform added to the angle calculation to create continuous rotation.
